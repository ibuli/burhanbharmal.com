Swiggy built ARD Automator, a cross-platform tool that automatically verifies thousands of mobile analytics events using machine-readable contracts. It reduced QA regression time by 66%, improved event coverage, and eliminated human errors, transforming what was once a manual, fragmented workflow into a fast, scalable, and self-maintaining system.

**Key Learnings from Swiggy’s Journey**

1\. Define Clear Contracts Early

Machine-readable contracts bridge the gap between Analytics and Engineering teams. 

2\. Automate Everything You Can

Manual QA for analytics is time-consuming and prone to errors. Automation not only improves speed but also consistency. 

3\. Centralize Knowledge

A Git-based repository with reviews and CI validation ensures a single, trusted source of truth. 

4\. Build for Scale

Kotlin Multiplatform allowed Swiggy to build once and deploy everywhere, saving time and effort. 

5\. Iterate Continuously

ARD Automator’s design evolved with feedback, ensuring teams could easily adopt it without steep learning curves.
