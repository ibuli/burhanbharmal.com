JavaScript was written in the past (2006-2015) with frameworks like jQuery and Backbone.js. Devs came up with creative solutions to overcome browser inconsistencies and language limitations before modern JavaScript features like \`fetch()\` and \`Object.assign()\`. For example, jQuery used clever tricks like method chaining with \`$('#element').addClass('active').fadeIn()\` and \`\[\].push.apply(this, num)\` to make jQuery objects behave like arrays.
