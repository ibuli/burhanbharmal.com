Chrome extension now live — install from the Chrome Web Store

- Arkive opens in every new tab for quick access to bookmarks, notes, and RSS

- Save pages, highlights, and quick notes in one click

- Sync RSS, Notes, and Bookmarks across devices without creating an account

- Privacy-first: all workspace data stays in your browser by default

Visit [https://arkive.me](https://arkive.me) and click on the Get Chrome Extension button on the home page.

Also, do upvote the project on launchpad - [Explore project](/work/arkive)
